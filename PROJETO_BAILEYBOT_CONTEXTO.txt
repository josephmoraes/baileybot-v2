# OBJETIVO

Sistema web para gerenciamento de clientes, campanhas e mensagens
via WhatsApp utilizando Baileys + SQLite + Express + Bootstrap.

A filosofia do projeto é:

- Código modular
- ES Modules (import/export)
- SQLite como banco principal
- Excel apenas para importação/exportação
- Interface Bootstrap
- Backend Express
- Frontend Vanilla JS
- Um arquivo por responsabilidade

REGRAS IMPORTANTES
====================================================

Sempre utilizar:

import/export

Nunca usar require()

Nunca criar arquivos gigantes.

controller
service
repository
router
frontend

====================================================
PRÓXIMO PASSO
====================================================

Finalizar módulo de Mensagens.

Depois iniciar Campanhas.

NÃO começar Assistente IA antes da V1 estar pronta.

====================================================
OBSERVAÇÕES
====================================================

O BaileyBot atualmente NÃO possui IA.

Ele apenas:

- envia mensagens
- gerencia clientes
- controla templates
- registra histórico

A IA será desenvolvida apenas após a conclusão da versão 1.
